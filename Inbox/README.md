# Inbox

This folder is for repo-tracked supplemental context provided for agents.

Items here are not active project source by default. Each item should be listed below with its source, purpose, editing rule, and status.

## Items
| Path | Source | Purpose | Editing rule | Status | Notes |
| --- | --- | --- | --- | --- | --- |
| TBD | TBD | TBD | TBD | new | Add items as they are provided |

## Status Values
- `new`: added but not reviewed.
- `triaged`: reviewed and summarized into durable docs or an execution plan.
- `promoted`: moved into active source or durable docs.
- `archived`: retained for history.
- `removed`: intentionally deleted.
