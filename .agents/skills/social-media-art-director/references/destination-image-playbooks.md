# Destination Image Playbooks

## Social Post

Use a strong focal point, simple scene, clear crop, and thumb-stopping contrast without clutter.

Common formats:

- Facebook feed: `4:5`, `1:1`, or `16:9`
- Instagram feed: `4:5` first, with `1:1` fallback
- Instagram story/reel cover: `9:16`
- Pinterest standard Pin: `2:3`, ideally `1000 x 1500`
- Threads image: `1:1` or `4:5`
- LinkedIn feed image: `1.91:1`, `4:5`, or `1:1`

Avoid small important details near edges.

## Platform-Specific Social Images

Match the image to the copy's platform behavior:

- Facebook conversation posts: use a natural, personable scene that makes the question easy to answer. Avoid overdesigned sale-card visuals.
- Instagram feed: use a strong product-in-environment or collector-detail scene with a clean focal point. Keep the subject centered enough for grid/profile crops; the image should carry the visual interest while the caption adds meaning.
- Pinterest: use a vertical `2:3` product/gift idea image where the item, occasion, and use context are clear at a glance. Prefer clean backgrounds and searchable visual context over tiny details; use readable text overlay only when it materially helps discovery.
- Threads: use an image only when it sharpens the joke, observation, or quick community prompt. Do not overproduce casual posts.
- LinkedIn: use process, workspace, packaging, batch-making, material, or decision-context visuals that support a maker/business insight.

If existing creative does not match the destination, note the needed replacement or crop in the copy review or image handoff. Do not generate a new image unless the user asks for it.

## Newsletter

Use a calm hero or section image that supports the copy without competing with layout.

Common formats:

- Hero: `16:9`, `3:2`, or wide crop
- Product block: `1:1` or `4:5`

Avoid text baked into images unless exact text is required.

## Blog Post

Use an editorial feature image that communicates topic and search intent.

Common formats:

- Feature image: `16:9` or `3:2`
- Inline explainer: `4:3`

Prioritize clarity over dramatic styling.

## Product Scene

Use realistic scale, believable contact shadows, and a context that shows use, mood, or giftability.

When reference images are supplied, preserve product identity over artistic novelty.

## Campaign Asset

Use a consistent visual system across variants:

- Shared color palette.
- Shared lighting.
- Similar crop logic.
- Clear difference in audience or message angle.
