# Copywriter Examples

## Social Post

Input:

```json
{
  "destination": "facebook",
  "audience": "gift buyers",
  "goal": "drive shop visits",
  "brand_voice": "warm, playful, handmade",
  "details": "New 3D printed desk duck, small collectible, bright yellow raincoat"
}
```

Output shape:

- Hook
- Body
- CTA
- Source facts used
- Review notes
