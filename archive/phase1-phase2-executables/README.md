# Archived Phase 1 And Phase 2 Executables

These files are kept as historical references from the Markdown-output era of the project:

- `demo_phase1.py`
- `demo_phase2.py`
- `cli_phase1_phase2.py`

They are no longer the supported day-to-day entry point.

The supported Phase 3 entry point is:

```bash
python run_local.py
```

The Phase 2 planner library remains active in `marketing_os/phase2.py` because Phase 3 uses it to generate database-backed plans.
